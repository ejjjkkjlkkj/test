# Non-Negotiable Invariants

A build is invalid if any of these fail.

ACCESSIBLE-BY-CONSTRUCTION
Every object has a semantic representation.

ACTION-EQUIVALENCE
Every legitimate operation has an equivalent universal interaction path.

MODALITY-NEUTRAL
No single human sense is the semantic source of truth.

UNKNOWN-SURVIVABILITY
Unknown object types remain inspectable and navigable.

DYNAMIC-CONTINUITY
State changes preserve navigable context.

INTERRUPTIBILITY
Presentation can be interrupted immediately.

COMPOSABILITY
Objects retain accessibility when embedded inside other objects.

NON-EXCLUSION
An application cannot opt out of intrinsic accessibility.

SECURITY-PRESERVATION
Accessibility does not bypass authorization or confidentiality.

FUTURE-PROOFING
New modalities and object types can be added without redesigning existing semantics.
