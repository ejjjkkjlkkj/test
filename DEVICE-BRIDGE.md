# ZERO — Pont machine

Le pont machine relie le noyau ZERO au matériel réel sans faire du pilote externe la source du sens.

## Responsabilité

Le pont traduit :

PHYSICAL STATE
→ MACHINE OBSERVATION

et :

SEMANTIC TRANSITION
→ PHYSICAL OPERATION

Il conserve :

IDENTITY
STATE
CAPABILITY
EVENT
SECURITY
UNCERTAINTY

## CPU

Le premier pont cible l'état d'exécution réellement disponible au niveau machine.

## GPU / moniteur

Le pont expose les capacités et états observables avant toute projection.

## Entrées / audio

Les signaux deviennent événements avant d'être interprétés comme commandes d'interface.

## Réseau

Les paquets et transports deviennent événements de communication. Leur représentation physique ne devient pas le modèle du langage.

## Principe

Un pont peut être spécifique au matériel.

Le langage ne doit pas devenir spécifique au pont.
