# ZERO — Noyau total

ZERO n'est pas un langage posé sur une machine.

ZERO définit un continuum :

PHYSIQUE
→ MACHINE
→ SENS
→ LANGAGE
→ OBJET
→ RELATION
→ INTERACTION
→ MONDE

Le même modèle s'applique au CPU, à un pixel, à une photo, à un iPhone distant, à une page web et à une action utilisateur.

## Unité fondamentale

L'unité fondamentale est l'entité sémantique.

Elle possède :

IDENTITY
MEANING
STATE
RELATIONS
CAPABILITIES
OBSERVATIONS
EVENTS
PROJECTIONS
SECURITY
UNCERTAINTY

Il n'existe pas d'objet « accessible » séparé d'un objet normal.

## Principes non négociables

1. Le sens précède la représentation.
2. L'identité n'est pas une adresse.
3. Une projection n'est pas la source de vérité.
4. Une modalité n'est jamais privilégiée.
5. L'inconnu reste représentable.
6. Toute transition possède un résultat observable.
7. Toute capacité est explicitement vérifiable.
8. Toute interruption est observable.
9. Le local et le distant utilisent le même modèle.
10. L'accessibilité commence au niveau machine.

## Fermeture

Une nouvelle entité doit pouvoir entrer dans ZERO sans nécessiter une nouvelle architecture d'accessibilité.

Une nouvelle modalité doit pouvoir utiliser les mêmes objets et intentions.

Une nouvelle machine doit pouvoir communiquer avec ZERO sans changer le noyau sémantique.

C'est le critère de fermeture du langage.
