# Accessible Boot

Boot is part of accessibility.

The machine must expose a semantic boot environment before an operating system exists.

Required concepts:

BOOT STATE
DEVICE DISCOVERY
INPUT
OUTPUT
ERROR
SECURITY
RECOVERY
CONFIGURATION
POWER
NETWORK

A boot interface must be navigable and operable through the universal interaction model.

The goal is not to attach a screen reader to firmware. The goal is for firmware itself to expose machine semantics from which speech, braille, keyboard, visual and other projections can be generated.

## Recovery

A failure must remain understandable and actionable.

A machine that can boot but cannot explain or safely recover from a failure is not universally accessible.
