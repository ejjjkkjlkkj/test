# ZERO — projection native de l'accessibilité

L'accessibilité n'est pas une couche qui reconstruit le sens après coup.

## Source unique

OBJECT + EVENT + OBSERVATION + RESULT

sont la source commune de toutes les projections.

## Projections

VOICE
BRAILLE
KEYBOARD
DISPLAY
POINTER
TOUCH
NETWORK
AUTOMATION

Aucune projection n'est prioritaire.

## Exemple

OBSERVE SATELLITE:test

peut produire simultanément :

VOICE → description sémantique
BRAILLE → structure navigable
KEYBOARD → actions disponibles
DISPLAY → représentation visuelle
NETWORK → représentation transmissible

Les projections ne modifient jamais l'objet source.

## Inconnu

Si une propriété est inconnue, la projection doit annoncer UNKNOWN et conserver l'incertitude.
