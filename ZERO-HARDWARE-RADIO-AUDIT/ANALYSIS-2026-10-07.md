## 2. Verdict matériel

### WIFI — PASS / PREUVE MATERIELLE FORTE

Le rapport contient une preuve PnP PCI directe :

`PCI\VEN_14C3&DEV_7961&SUBSYS_46801A3B&REV_00\4&303B37F5&0&0012`

Identité déclarée :
`MediaTek Wi-Fi 6 MT7921 Wireless LAN Card`

`OK`

Le périphérique est donc identifié au niveau PCI/PnP comme matériel radio Wi-Fi, et pas uniquement comme adaptateur logiciel.

Le rapport fournit en plus :
- pilote : MediaTek Wi-Fi 6 MT7921 Wireless LAN Card
- service : `mtkwlex`
- interface : Wi-Fi
- état : Up / connecté
- radio : 802.11ax
- bande observée : 5 GHz
- connexion active

Conclusion Wi-Fi : **HARDWARE RADIO CONFIRMED**.

### WWAN / CELLULAIRE — NON PROUVE

La section intitulée `WWAN CELLULAIRE MODEM` contient uniquement des composants Realtek Audio / SoftwareComponent.

Aucun modem cellulaire WWAN matériel n'est démontré dans cette section.

Conclusion : **NO WWAN HARDWARE PROOF IN THIS AUDIT**.

## 3. Défauts de méthode détectés

### Défaut A — section WWAN incorrecte

Le titre `WWAN CELLULAIRE MODEM` est incompatible avec les données qu'il contient :
- Realtek Audio
- Realtek Audio Universal Service
- Realtek ASIO
- Realtek Audio Effects

Cette section doit être renommée ou remplacée par une vraie collecte WWAN.

### Défaut B — RADIO mélange matériel et logiciel

La section `RADIO` mélange :
- matériel PCI MediaTek Wi-Fi ;
- matériel USB MediaTek Bluetooth ;
- périphériques `SWD\RADIO` ;
- Wi-Fi Direct virtuel ;
- composants Realtek Audio ;
- endpoints audio.

Elle ne doit pas être utilisée seule comme preuve de matériel radio.

### Défaut C — RADIO CANDIDATES = faux comptage

Le résumé annonce :

`RADIO CANDIDATES: 24`

Mais plusieurs entrées sont manifestement audio ou logicielles.

Le nombre 24 ne doit donc pas être interprété comme « 24 radios matérielles ».

### Défaut D — périphériques fantômes

La section `PERIPHERIQUES RADIO NON OK` contient :

`Realtek 8812BU Wireless LAN 802.11ac USB NIC`
avec :
`CM_PROB_PHANTOM`

et :
- Wi-Fi 2 — phantom
- Wi-Fi Direct Virtual Adapter #3 — phantom
- Wi-Fi Direct Virtual Adapter #4 — phantom

Ces éléments doivent être classés comme **résidus/énumérations fantômes**, et non comme matériel radio actuellement présent.

## 9. Conclusion

Le fichier est exploitable, mais son agrégation actuelle n'est pas encore une preuve formelle « hardware-only ».

La preuve matérielle la plus solide est obtenue en remontant les chaînes :

`PCI -> PNPDeviceID -> MediaTek MT7921 -> mtkwlex -> Wi-Fi`

et

`USB -> PNPDeviceID -> MediaTek Bluetooth Adapter -> BTHUSB -> Bluetooth`

La prochaine étape correcte est donc de produire une **cartographie radio normalisée**, sans compter les composants audio, virtuels ou fantômes comme du matériel radio.
