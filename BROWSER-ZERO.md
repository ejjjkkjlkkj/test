# ZERO — Navigateur natif

Le navigateur ZERO n'est pas un navigateur existant auquel on ajoute une accessibilité.

Il est une application du langage ZERO.

## Web comme monde sémantique

Une connexion distante produit :

REMOTE
→ DOCUMENT / APPLICATION / SERVICE
→ OBJECT GRAPH
→ EVENTS
→ INTERACTION

HTML, CSS, scripts, images, vidéos, formulaires et interfaces distantes sont des sources de phénomènes à représenter.

Le DOM n'est pas la définition du modèle ZERO.

## Image

Une image peut exposer :

SCENE
REGIONS
OBJECTS
TEXT
RELATIONS
UNCERTAINTY
ACTIONS

La projection visuelle reste disponible, mais n'est pas obligatoire pour comprendre ou interagir.

## CAPTCHA

ZERO représente la tâche, les règles et les interactions effectivement disponibles.

Il ne déclare pas une tâche inaccessible simplement parce que son rendu initial est visuel.

## Réseau

Le navigateur utilise le même modèle que les autres communications :

DISCOVER
CONNECT
AUTHENTICATE
OBSERVE
REQUEST
EVENT
RESULT

## Accessibilité

La navigation web et la navigation machine utilisent le même noyau d'interaction.
