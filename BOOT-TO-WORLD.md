# ZERO — De l'allumage au monde

Le chemin complet visé est :

POWER
-> FIRMWARE
-> CPU
-> MEMORY
-> DEVICE DISCOVERY
-> MACHINE STATE
-> ZERO CORE
-> LANGUAGE
-> NETWORK
-> OBJECT WORLD
-> UNIVERSAL INTERACTION

## Principe

Il ne doit pas exister de trou conceptuel où l'accessibilité disparaît entre le firmware et le langage.

Le CPU exécute.

La mémoire conserve.

Les périphériques produisent des observations et événements.

Le noyau construit les relations sémantiques.

Le langage exprime les transitions.

Les projections rendent les mêmes informations accessibles selon la modalité choisie.
