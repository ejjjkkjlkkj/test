# Universal Navigation

Navigation is semantic, not tied to a mouse, touchscreen, visual focus rectangle, or DOM.

The runtime provides:

NEXT
PREVIOUS
ENTER
EXIT
INSPECT
ACTIVATE
EDIT
SELECT
READ
COMPARE
SEARCH
BACK
FORWARD
INTERRUPT

Every operation is defined against semantic objects and relations.

A modality chooses how the operation is expressed physically.

Keyboard, speech, braille, visual pointing, audio, and future modalities therefore address the same navigation model.
