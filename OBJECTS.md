# Universal Object Model

The model must cover both known and unknown things.

Examples:

text
image
photo
diagram
chart
table
video
audio
map
3D scene
game
web page
application
terminal
document
form
notification
CAPTCHA
remote interface
future object type

## Image

An image is not represented as "image".

It is represented as a semantic scene containing entities, text, spatial relations, actions, uncertainty, and provenance when available.

## Chart

A chart exposes axes, series, values, relations, trends, anomalies, and underlying data when available.

## CAPTCHA

A CAPTCHA is represented by its actual task and available legitimate interaction channels. The universal model must seek an equivalent task completion path rather than merely describing the challenge.

## Dynamic content

Changing content is an event stream over semantic objects. The user can navigate changes without losing context.

## Unknown content

Unknown content is decomposed instead of being declared inaccessible.
