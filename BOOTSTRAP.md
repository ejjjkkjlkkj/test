# Bootstrap

The bootstrap must eventually prove that the language can execute without inheriting an existing accessibility framework as its foundation.

Stages:

0. Define semantic object algebra.
1. Define intrinsic accessibility invariants.
2. Define universal navigation.
3. Define native execution representation.
4. Define input/output events.
5. Define modality projections.
6. Implement a minimal executable kernel.
7. Implement the browser as a native application of the language.
8. Consume arbitrary content through the universal object model.
9. Validate unknown objects and adversarial interfaces.

The first implementation is deliberately small. Features are admitted only when they preserve the universal invariants.
