# ZERO — I/O machine universelle

Toutes les entrées et sorties convergent vers le même modèle.

## Entrées

CPU interruption
GPU event
keyboard signal
pointer signal
touch signal
audio input
sensor event
network event
firmware event

→ OBSERVATION
→ EVENT
→ INTENT

## Sorties

RESULT
→ PROJECTION
→ physical device

Exemples :

RESULT → monitor
RESULT → GPU
RESULT → speaker
RESULT → braille device
RESULT → network
RESULT → storage

## Aucun périphérique privilégié

Le moniteur n'est pas la vérité.

La parole n'est pas la vérité.

Le braille n'est pas la vérité.

Le clavier n'est pas la vérité.

Le réseau n'est pas la vérité.

Le sens commun est la vérité ; les périphériques sont des projections et des sources d'observation.
