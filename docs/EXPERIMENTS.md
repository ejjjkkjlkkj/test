# Experimental protocol

Le benchmark ne mesure pas « qui parle le mieux ».

Il mesure si le moteur :
- reconnaît une hypothèse cachée ;
- provoque une confrontation ;
- sait changer de représentation ;
- évite de répéter exactement une impasse ;
- conserve une leçon d'une expérience précédente.

Aucune victoire n'est déclarée à partir d'un score fabriqué par le moteur lui-même. Les futurs benchmarks doivent être vérifiables indépendamment.

## Prochaine rupture recherchée

Le moteur actuel possède encore des règles écrites à la main. C'est volontairement la première cage expérimentale.

La prochaine génération doit découvrir de nouvelles opérations de transformation à partir des traces d'échecs, au lieu de choisir seulement parmi des transformations écrites à l'avance.

C'est là que commence la vraie recherche.
