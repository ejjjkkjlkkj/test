# Self-expansion experiment

The fixed strategy list is no longer the intended endpoint.

A discovered strategy is represented as data: a small executable program made from transformation steps. Discovery can combine steps, the archive measures repeated trials, and weak strategies are removed.

Evaluation uses held-out tasks generated separately from discovery traces. The system must earn survival through outcomes instead of simply appearing novel.

This is still scaffolding, not proof of intelligence. The decisive future test is to remove more hand-written strategy knowledge while preserving an executable discovery loop and then measure transfer on tasks that were not used to construct the strategies.
