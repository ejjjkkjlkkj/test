# ZERO

The system begins without assuming that an existing theory is the correct architecture.

No pretrained model. No external inference service. No copied commercial architecture. No theorem is the foundation.

The implementation is an experiment, not a claim of intelligence.

The crucial constraint is self-reconstruction: hand-written operations are scaffolding only. The next generation should learn which transformations are useful from trajectories, failures and consequences, then invent combinations not explicitly supplied by the author.

Evidence beats rhetoric:
- unseen tasks;
- reproducible runs;
- independent success criteria;
- measured failure recovery;
- discovery of transformations not present in the initial seed.

Goal: continuously increase capability without continuously increasing hand-written answers.
