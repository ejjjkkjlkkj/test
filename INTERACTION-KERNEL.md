# ZERO — Noyau d'interaction universel

Toutes les modalités convergent vers un même noyau.

## Entrée

PHYSIQUE
-> OBSERVATION
-> ÉVÉNEMENT
-> INTENTION

## Interaction

INTENTION
-> TARGET
-> CAPABILITY CHECK
-> TRANSITION

## Sortie

TRANSITION
-> RESULT
-> OBSERVATION
-> PROJECTION

## Actions fondamentales

OBSERVE
NAVIGATE
INSPECT
SELECT
ACTIVATE
EDIT
CREATE
MOVE
COMPARE
SEARCH
INTERRUPT
BACK
FORWARD

La liste n'est pas fermée : de nouvelles actions peuvent être décrites sémantiquement.

## Modalités

Une intention peut venir de :

- clavier ;
- parole ;
- braille ;
- pointeur ;
- tactile ;
- automatisation ;
- réseau ;
- future modalité.

Aucune modalité ne possède une action différente lorsqu'elle vise le même objet et le même résultat.
