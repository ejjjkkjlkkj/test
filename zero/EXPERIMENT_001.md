# EXPERIMENT 001 — Transformation avant réponse

## Hypothèse

Une intelligence expérimentale peut être recherchée sans commencer par un mécanisme de prédiction.

Le système reçoit une situation, la transforme de plusieurs façons, puis observe les conséquences de ses propres transformations.

## Ce qui est volontairement absent

- modèle pré-entraîné ;
- apprentissage supervisé ;
- réseau neuronal ;
- représentation vectorielle ;
- API ;
- bibliothèque d'IA ;
- théorème mathématique comme principe directeur.

## Ce qui est testé

**Percevoir → transformer → confronter → retenir → transformer encore.**

Le point important est que la mémoire porte sur les **transformations** et pas uniquement sur les réponses.

## Prochaine expérience

Faire évoluer le moteur pour qu'il puisse découvrir lui-même de nouvelles opérations à partir des opérations existantes, puis tenter de casser ses propres opérations.

Critère de réussite : produire une transformation non prévue explicitement par le programme initial et démontrer son utilité sur un problème inédit.
