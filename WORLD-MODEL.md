# ZERO — Modèle du monde

ZERO doit pouvoir représenter un monde qui dépasse les objets prévus au moment de la conception.

## Ce qui appartient au monde

- machine ;
- CPU ;
- mémoire ;
- GPU ;
- moniteur ;
- audio ;
- entrées ;
- stockage ;
- réseau ;
- firmware ;
- application ;
- document ;
- texte ;
- image ;
- photo ;
- graphique ;
- tableau ;
- vidéo ;
- audio ;
- carte ;
- jeu ;
- formulaire ;
- CAPTCHA ;
- interface distante ;
- appareil externe ;
- objet futur ou inconnu.

## Même noyau

Chaque élément devient un objet sémantique.

LOCAL et DISTANT ne sont pas deux modèles d'objet.

KNOWN, PARTIALLY-KNOWN et UNKNOWN sont des niveaux de connaissance.

## Découverte continue

ZERO peut enrichir un objet après sa création :

EXISTENCE
-> IDENTITÉ
-> STRUCTURE
-> SENS
-> CAPACITÉS
-> RELATIONS
-> ÉVÉNEMENTS

Une connaissance nouvelle complète l'objet au lieu de remplacer arbitrairement sa représentation précédente.

## Principe

Le langage doit pouvoir fonctionner dans un monde qui n'a pas été entièrement prévu par ses concepteurs.
